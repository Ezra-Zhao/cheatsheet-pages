How to find all files with an extension — find -name

You need every .log file in a tree, wherever it hides.

Examples run in the current directory tree — swap the starting path for any directory. Commands are GNU findutils (find / xargs); BSD/macOS versions differ in a few flags.

find . -name "*.log"        # every .log file under the current directory
find /var/log -name "*.gz"  # ...or start from any directory you name

Good to know

The pattern matches the base name only, it is a shell-style glob (not a regex), and it is case-sensitive.
