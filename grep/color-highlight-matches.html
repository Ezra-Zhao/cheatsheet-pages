How to highlight matches in color — grep --color

Matches should light up in the terminal — or in a pager that renders escapes.

Examples run against a small fixture tree (proj/ with logs, sources, a binary file and symlinks) — swap in your own paths. Commands run-verified on GNU grep 3.11; BSD grep differences are noted in the sheet.

grep --color=always 'ERROR' proj/app.log | less -R   # the match is wrapped in ANSI color escapes
grep --color=auto 'ERROR' proj/app.log               # color only when output is a terminal

Good to know

--color=auto is why grep colors matches interactively but not in pipes. Force it with always when the consumer renders escapes. Colors are tunable via GREP_COLORS.
