How to measure lines and find the longest — awk length()

Which lines are suspiciously long — and which single line is the longest of all?

Examples read small fixture files (scores.txt, access.log, app.log) — swap in your own. Commands run-verified on mawk 1.3.4; the gawk-only extensions (gensub, BEGINFILE, FPAT) are deliberately not used.

awk '{print length($0), $0}' words.txt     # characters in the string (an empty line scores 0)
awk 'length($0) > 10 {print}' words.txt    # the same call used as the pattern: only long lines pass
awk '{if (length($0) > max) {max = length($0); line = $0}} END {print max, line}' app.log   # keep the champion, report at END

Good to know

Called with no argument, length() measures $0. Careful: the GNU Awk manual defines the count in characters, but mawk counts bytes — a 4-character CJK string measures 12 there. The longest-line skeleton is the general keep-the-champion pattern.
